# Frames by Jesh — V2 Portfolio

This version keeps the exact dark cinematic glassmorphism theme and adds:

- 12 SEPARATE photography placeholders
- 6 SEPARATE YouTube video cards
- Full-screen hero background video loop
- Dedicated Showreel section with looping local video
- Existing before/after editing slider
- Floating contact badge
- Responsive desktop/tablet/mobile layout

## Hero Reel

Put your video here:

assets/videos/hero-reel.mp4

It is already configured as:
autoplay + muted + loop + playsinline

## Showreel

Put your video here:

assets/videos/showreel.mp4

It is configured to autoplay muted and loop, with controls available.

## Six YouTube videos

Open `index.html` and find:

VIDEO_ID_01
VIDEO_ID_02
VIDEO_ID_03
VIDEO_ID_04
VIDEO_ID_05
VIDEO_ID_06

Replace each with the actual YouTube video ID.

Example:
https://www.youtube.com/watch?v=ABC123XYZ

ABC123XYZ
